Security

Antinuke stops rogue admins from tearing the server down. Antiraid can kick or ban mass joins and brand-new accounts. Both are off by default — antinuke is owner-only, antiraid needs Manage Server.

Tickets

Post an Open Ticket panel, set a support role, and let staff claim or close tickets. Closing a ticket saves a .txt transcript.

Voice channels

Set up Join-to-Create channels with ,voicemaster setup. The VoiceMaster panel lets channel owners lock, ghost, claim, and more. Temporary channels delete themselves when empty.

Questions, answered honestly

Answers to the usual questions, plus a link to the kyōki support server.

What is the command prefix?

The prefix is a comma, as in ,ban. There are 529 commands (aliases not counted), plus slash versions of ban, kick, timeout, purge, warn, help, and confess. Use ,help for the full list, or ,help ban for details on one command.

Is kyōki free?

Yes. There is no paid plan on this site, and we do not sell a premium tier here.

Which permissions does it need?

The Add kyōki button requests the permissions the bot needs. Review the exact list on Discord’s invite screen before you approve.

How do I get support?

Join the kyōki support server at discord.gg/j6WTTyKDeM.
