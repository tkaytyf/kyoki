Changelog

Only things that have actually happened. Dates are in America/Los_Angeles.

20 November 2026

Wave 6

  • Wave 6 is live: 1,011 commands plus 7 slash commands (/ban, /kick, /timeout, /purge, /warn, /help, and /confess). Every command and subcommand is counted once; aliases are not counted. This wave passes 1,000 commands.
  • New modules include messaging (,say and ,edit post and edit plain text as kyōki), 36 text tools, and 28 utility tools. Also added: server and permission management, ticket and starboard extras, ,quirk, and ,emojiquiz. The site’s command list and docs were rebuilt from that list.
20 November 2026

Wave 5

  • Wave 5 is live: 861 commands plus 7 slash commands (/ban, /kick, /timeout, /purge, /warn, /help, and /confess). Every command and subcommand is counted once; aliases are not counted.
  • New modules include mini-games, staff application forms, and social commands for marriage and reputation. Economy gained fishing, mining, jobs, pets, heists, and crafting. Roles gained dropdown role menus. Embeds gained a button builder, link buttons, and saved embeds. Utility gained to-do lists, Discord timestamps, countdowns, and highlights. Automod can auto-punish and has more filters. Backups can import and export layout files. The site’s command list and docs were rebuilt from that list.
20 November 2026

Wave 4

  • Wave 4 is live: 722 commands plus 7 slash commands (/ban, /kick, /timeout, /purge, /warn, /help, and /confess). Every command and subcommand is counted once; aliases are not counted.
  • New modules include boosts and vanity rewards, automation (autoroles, auto-threads, join DMs, media-only channels, ping on join), channel and thread tools, and webhooks. Logging can split categories across channels. Starboard and embeds gained more subcommands. The site’s command list and docs were rebuilt from that list.
  • kyōki’s replies now use Discord’s newer message layout, with no colored side bar.
  • The default VoiceMaster panel is a compact card: a one-line hint, the 10 original emoji buttons in two rows, and a line pointing to Join to Create. ,vm rename and ,vm limit stay as commands. ,vm style classic brings back the usage list.
20 November 2026

Support server

  • The kyōki support Discord is open. Join it from Support in the nav or footer, or at discord.gg/j6WTTyKDeM. A short /support redirect is on the site. Vote and the dashboard stay coming soon.
20 November 2026

Wave 3

  • New modules include fun, lookups, emoji and stickers, ticket forms, alerts (YouTube now; Twitch alerts are not available yet), feeds (RSS/Atom works; Reddit feeds may be unreliable), modmail, suggestions, invite tracking, tags, birthdays, bump reminders, confessions, counters, counting, polls, temp roles, reaction triggers, and Top.gg vote rewards. The site’s command list and docs were rebuilt from that list.

20 November 2026

Website

  • The site now has a privacy page, terms, a press kit, a short invite link, and a 404 page. The press kit includes official logos, banners, emojis, and a promo video. It also has a live demo, a setup checklist, a page for each command, and a light mode. The homepage carries the intro video and a before/after graphic; the press kit adds mascot moods, stickers, card backgrounds, and feature-of-the-week posts.
20 November 2026

Wave 1

20 November 2026

What’s new

  • VoiceMaster is in the bot: Join-to-Create channels and a panel for lock, ghost, claim, and the rest of the owner controls. Temporary channels delete themselves when empty.
  • This website is up as a preview — including commands, status, docs, an embed builder, and a dashboard page. Dashboard login is not open yet.
  • kyōki’s own embeds use a plain gray color (#2B2D31) so the left bar doesn’t flash a stripe.
  • The command list grew to the full set: tickets, antinuke and antiraid (both off by default), jail, giveaways, starboard, autoresponder, a per-server prefix, utility commands, and ,embed. Slash commands landed for /ban, /kick, /timeout, /purge, /warn, and /help. The site’s command list and docs were rebuilt from that list.
