Pitch

kyōki (狂気, “madness”) is an all-in-one Discord bot. It ships 335 commands — every command and subcommand counted once; aliases not counted — plus slash versions of ban, kick, timeout, purge, warn, and help. The default prefix is a comma, as in ,ban. It covers moderation, cases, automod, roles, reaction roles, security, tickets, voice, sticky messages, welcomes, welcome cards, logging, embeds, giveaways, starboard, autoresponder, utility, levels and rank cards, economy and shop, Roblox verification, backups, and server templates. Antinuke and antiraid stay off until a server turns them on.
