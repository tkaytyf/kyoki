Commands

The default prefix is a comma, as in ,ban. Change it per server with ,prefix. Mentioning the bot always works. Slash versions: /ban, /kick, /timeout, /purge, /warn, and /help. Antinuke and antiraid are off by default.

  • Command: ,kick Also /kick

    Kick a member from the server.

    Permission: ⚠️ Kick Members

    Syntax: ,kick <member> [reason]

    Example: ,kick @user spamming

    Slash: Slash options: member, reason.

  • Command: ,ban Also /ban

    Ban a user from the server.

    Permission: ⚠️ Ban Members

    Syntax: ,ban <user> [reason]

    Example: ,ban @user spamming

    Slash: Slash options: user, reason, delete_days (0–7).

  • Command: ,unban

    Unban a user by their ID.

    Permission: ⚠️ Ban Members

    Syntax: ,unban <user id> [reason]

    Example: ,unban 123456789012345678

  • Command: ,timeout Also /timeout

    Time out a member for a set duration.

    Permission: ⚠️ Moderate Members

    Syntax: ,timeout <member> <duration> [reason]

    Aliases: `,to`, `,mute`

    Example: ,timeout @user 10m

    Slash: Slash options: member, duration (0 removes the timeout), reason.

  • Command: ,untimeout

    Remove a member's timeout.

    Permission: ⚠️ Moderate Members

    Syntax: ,untimeout <member>

    Aliases: `,unmute`

    Example: ,untimeout @user
